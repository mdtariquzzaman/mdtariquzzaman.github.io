# Academic website

Source for [mdtariquzzaman.github.io](https://mdtariquzzaman.github.io/).

## About the site

The site has four pages: **Home**, **Publications**, **CV**, and **Personal**, with a shared GBA-era menu style: quiet pixel frames, compact record panels, and readable monospace copy. Parchment-and-teal day and evening-indigo night themes pair a minimal pixel sky with an original day/night still-life of a bookshelf, window, and coffee cup. Home has two independent windows: a profile with the real portrait on the left, and the illustration with social buttons below it on the right. At 900px and below, the windows stack in that order. Pages are generated with Python’s standard library and served as plain HTML and CSS. Content and navigation work without JavaScript; optional JavaScript provides theme switching, publication drawers, figure carousels, section highlighting, a reading gauge, and subtle pixel animations that a header button can pause. Fonts and artwork are self-hosted; no package installation or external font service is required.

The CV webpage shares the design and follows the current owner-supplied CV for education, research, technical skills, teaching, industry experience, awards, certifications, and languages. Research interests and publications stay on their existing Home and Publications pages. Webpage edits leave the downloadable PDF and its compilation sources and fonts unchanged.

### IUT publication CSV

`publication_input_iut_website.csv` is prepared for the publication importer at the [IUT faculty profile](https://cse.iutoic-dhaka.edu/profile/tariquzzaman/publications). Keep the header exactly as `Type,Date,Info`, use an ISO date (`YYYY-MM-DD`), and quote each complete citation in `Info` so commas do not create extra columns.

Write each `Info` value as a readable scholarly citation: preserve the approved author order, put the complete paper title in quotation marks, include the actual venue or repository and year, and finish with the canonical external publication URL. Use the publication host (for example, ACL Anthology or arXiv) as the final link so search engines and visitors reach the paper record directly; do not link to this website or the IUT profile from the citation. ArXiv-only papers are preprints and must use `Others` in `Type`, with wording such as `arXiv preprint, arXiv:<identifier> (<year>)`. Keep a workshop or conference classification when the work has an approved workshop/conference venue even if its accessible paper copy is hosted on arXiv.

When adding or changing a row, validate the file before importing it:

```sh
python3 - <<'PY'
import csv
with open('publication_input_iut_website.csv', newline='') as f:
    rows = list(csv.DictReader(f))
assert all(set(row) == {'Type', 'Date', 'Info'} for row in rows)
assert all(row['Date'].count('-') == 2 for row in rows)
assert all(row['Type'] == 'Others' for row in rows if 'arXiv' in row['Info'])
print(f'{len(rows)} publication rows are valid')
PY
```

## Google Scholar metrics

`scripts/sync_scholar.py` refreshes the citation, h-index, and i10-index summary in `content/scholar-metrics.json`. It does not import papers; those are curated in `content/publications.json`. Google Scholar blocks requests from cloud servers such as GitHub Actions, so run it by hand from your own connection:

```sh
python3 scripts/sync_scholar.py            # fetch, save, and rebuild the site
python3 scripts/sync_scholar.py --dry-run  # fetch and print only
```

A successful run prints `Scholar metrics updated` (or `unchanged`) with the values, sets the refreshed date to today, and rebuilds the pages. Any failure — a Scholar block, a CAPTCHA page, a missing or malformed metrics row, or a certificate problem — prints `SYNC FAILED` with the reason, changes nothing, and exits with status 1, so there is no need to cross-check the numbers. On a macOS python.org install, a certificate error is fixed once by running `Install Certificates.command` from the Python folder in `/Applications`.

## Deployment

GitHub Pages serves the `main` branch from the repository root (**Settings → Pages → Source: Deploy from a branch**, `main`, `/ (root)`); `.nojekyll` keeps the files served as-is. Publish only when requested. Verify the project Git root and remote before staging, then rebuild if needed, commit, and push:

```sh
git rev-parse --show-toplevel
git remote -v
python3 scripts/sync_scholar.py   # optional: refresh metrics and rebuild
git add -A
git commit -m "Update site"
git push
```

## Artwork and fonts

Pixel UI text uses **Pixel Operator Mono** by Jayvee Enaguas; body copy uses **IBM Plex Mono**. The fonts are loaded from `assets/fonts/` without a hosted font service. Shared topic and UI icons are inline SVG paths rendered by the builder.

The Home artwork is based on an original paired day/night still-life created with ImageGen: a bookshelf with books, a window, a coffee cup on the sill, and plain wall/sky. The Home’s animated variants add a small blocky pixel cat looking out the window; its tail makes an ultra-light left/right wiggle along the sill across four looping frames in both themes. The night window has a few restrained pixel stars with one small glow. There is no human, desk, laptop, notes, or other extra prop. The gentle Japanese influence comes through wood, paper, and restraint. [reading-corner-day.webp](assets/illustrations/reading-corner-day.webp) and [reading-corner-night.webp](assets/illustrations/reading-corner-night.webp) retain the 1536x1024 source composition, while [reading-corner-day.gif](assets/illustrations/reading-corner-day.gif) and [reading-corner-night.gif](assets/illustrations/reading-corner-night.gif) are the compact 512x341 web variants; [prompts.json](assets/illustrations/prompts.json) records their creation and animation. [sky-day.svg](assets/sky-day.svg) and [sky-night.svg](assets/sky-night.svg) provide minimal coded pixel-sky backdrops above full-width CSS sky bands.

The day GIF's wall is sage rather than the source's lavender: only its lavender wall entries and one dim sunbeam tone were shifted in the GIF color tables, a lossless edit that leaves every pixel, frame, and timing in place. With JavaScript, [scenes.js](assets/scenes.js) draws original code-generated pixel animation in whole art pixels with ordered dithering and no smoothing. The sky's clouds drift and a small flock of birds sometimes passes by day; by night the stars twinkle and a shooting star occasionally crosses the margins. Its first frame matches the SVGs, so the canvas replaces them without a jump. Over the Home still-life, steam rises from the coffee, clouds and an occasional bird pass behind the window glass, and dust glints in the sunbeams by day; at night the window stars twinkle and a shooting star sometimes crosses. The cat's tail remains the GIF's own. Scenes run only while visible in a visible tab and show still frames under reduced motion or while the header's pause button holds them; the site remembers that choice. Day and night switch through a pixel-dither dissolve where View Transitions are available.

The right Home window, “Find me online”, keeps its LinkedIn, Bluesky, Twitter, ORCID, and Hugging Face buttons below the illustration at every width. It contains no Email or Publications/Personal quicklinks. The profile window keeps its existing contact/CV actions, and the normal research, Recent, Personal, and contact sections remain below the two windows.

Day uses `#f2e9d8` surroundings, `#fff7e8` panels, `#1e2a32` ink, `#29434a` teal frames with `#bdd3c7` sage title strips, and `#a64a35` accents. Night uses `#181d30` surroundings, `#262c43` panels, and `#e7b3a4` accents with light text.
