## Publications

### [Same Claim, Different Judgment: Benchmarking Scenario-Induced Bias in Multilingual Financial Misinformation Detection](https://aclanthology.org/2026.findings-acl.479/)

MFMD-Scen tests whether large language models judge the same financial misinformation claim consistently when the surrounding role, region, personality, ethnicity, or religion changes. The benchmark spans English, Chinese, Greek, and Bengali and evaluates 22 mainstream models.

[![Findings of ACL 2026](https://img.shields.io/badge/Findings_of_ACL_2026-425b46?style=flat-square)](https://2026.aclweb.org/program/findings/) [![Paper](https://img.shields.io/badge/Paper-68665d?style=flat-square)](https://aclanthology.org/2026.findings-acl.479/) [![Code](https://img.shields.io/badge/Code-68665d?style=flat-square&logo=github&logoColor=white)](https://github.com/lzw108/FMD)

### [Prompting with Sign Parameters for Low-resource Sign Language Instruction Generation](https://arxiv.org/abs/2508.16076)

BdSLIG is a Bengali sign-language instruction-generation dataset. The paper introduces Sign Parameter-Infused prompting, which adds structured cues such as hand shape, movement, location, and orientation to prompts so vision-language models can produce more reproducible instructions.

[![CV4A11y workshop at ICCV 2025](https://img.shields.io/badge/CV4A11y_Workshop_%40_ICCV_2025-425b46?style=flat-square)](https://cv4a11y.github.io/ICCV2025/index.html) [![Paper](https://img.shields.io/badge/Paper-68665d?style=flat-square&logo=arxiv&logoColor=white)](https://arxiv.org/abs/2508.16076) [![Video](https://img.shields.io/badge/Video-68665d?style=flat-square&logo=googledrive&logoColor=white)](https://drive.google.com/file/d/10QgGeiHcLzH5HIqXrYUBx6rw_9PpZMZk/view) [![Dataset](https://img.shields.io/badge/Dataset-68665d?style=flat-square&logo=huggingface&logoColor=white)](https://huggingface.co/datasets/aplycaebous/BdSLIG) [![Code](https://img.shields.io/badge/Code-68665d?style=flat-square&logo=github&logoColor=white)](https://github.com/mdtariquzzaman/SPIP)

### [the_linguists at BLP-2023 Task 1: A Novel Informal Bangla Fasttext Embedding for Violence Inciting Text Detection](https://aclanthology.org/2023.banglalp-1.26/)

The paper introduces an informal Bangla FastText embedding trained on 3.8 million informal text samples. Paired with lightweight classifiers, it targets violence-inciting text detection while reducing training and inference cost compared with transformer-based alternatives.

[![BLP workshop at EMNLP 2023](https://img.shields.io/badge/BLP_Workshop_%40_EMNLP_2023-425b46?style=flat-square)](https://blp-workshop.github.io/2023/accepted) [![Best Shared Task Paper Award](https://img.shields.io/badge/Best_Shared_Task_Paper_Award-a3864e?style=flat-square)](https://blp-workshop.github.io/2023/awards) [![Paper](https://img.shields.io/badge/Paper-68665d?style=flat-square)](https://aclanthology.org/2023.banglalp-1.26/) [![Video](https://img.shields.io/badge/Video-68665d?style=flat-square)](https://aclanthology.org/2023.banglalp-1.26.mp4) [![Dataset](https://img.shields.io/badge/Dataset-68665d?style=flat-square&logo=github&logoColor=white)](https://github.com/blp-workshop/blp_task1) [![Code](https://img.shields.io/badge/Code-68665d?style=flat-square&logo=github&logoColor=white)](https://github.com/mdtariquzzaman/VITD)

### [BDA: Bangla Text Data Augmentation Framework](https://arxiv.org/abs/2412.08753)

BDA combines rule-based and pretrained-model augmentation methods for Bangla text, then filters generated examples with semantic and lexical similarity checks. Across five datasets, the framework reaches performance comparable to full-data training while using half the training data.

[![arXiv preprint · 2024](https://img.shields.io/badge/arXiv_preprint_%C2%B7_2024-425b46?style=flat-square&logo=arxiv&logoColor=white)](https://arxiv.org/abs/2412.08753) [![Paper](https://img.shields.io/badge/Paper-68665d?style=flat-square&logo=arxiv&logoColor=white)](https://arxiv.org/abs/2412.08753) [![Code](https://img.shields.io/badge/Code-68665d?style=flat-square&logo=github&logoColor=white)](https://github.com/mdtariquzzaman/Bangla-Text-Augmentation-Framework)
